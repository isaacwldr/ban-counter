# Ban Counter Privacy Policy

Last updated: August 28, 2026

Ban Counter is a Discord bot that detects joking or conversational requests to ban Discord users and keeps a count of those requests.

## Information Ban Counter Accesses

Ban Counter receives new messages sent in Discord channels where the bot has permission to view messages.

Message content is processed in real time only to determine whether a message contains a ban request and which Discord user or users are being referenced.

Ban Counter does not retrieve or scan historical message logs.

## Information Ban Counter Stores

When a ban request is detected, Ban Counter may store:

- Discord server ID
- Discord user ID of the person referenced in the ban request
- Discord user ID of the person who submitted the request
- Discord message ID
- Date and time the request was recorded

Ban Counter may also use Discord user IDs for configuration purposes, such as aliases or abuse-prevention settings.

**Discord message content is not stored.**

## How Information Is Used

Stored information is used only to provide Ban Counter functionality, including:

- Maintaining ban-request counts
- Reporting those counts
- Identifying referenced Discord users
- Preventing abuse or spam

## Data Sharing

Ban Counter does not sell user data.

Ban Counter does not use user data for advertising.

Stored Discord data is not shared with third parties except where required by law.

## Data Retention and Deletion

Ban-request records are retained while needed to provide the bot's functionality.

The bot operator can delete:

- All Ban Counter data associated with a specific Discord server
- All stored Ban Counter data

Users or server administrators may request deletion of applicable stored data by contacting the bot operator.

If Ban Counter is permanently discontinued, stored ban-request data will be deleted.

## Security

Ban Counter's stored database is not publicly accessible.

Access to stored data is limited to the bot operator.

This privacy policy may be updated if Ban Counter's functionality or data practices change.
